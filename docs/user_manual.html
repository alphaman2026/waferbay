FEEG_ESD_eSCOPE 사용 설명서

BIGTREETECH SKR mini E3 (Marlin) 모터 제어 + Analog Discovery 2 파형 표시 PC 프로그램  |  v1.0.0

1. 프로그램 개요

FEEG_ESD_eSCOPE 는 하나의 화면에서 두 장비를 동시에 다루는 통합 제어 프로그램입니다.

장비연결 방식기능
BIGTREETECH SKR mini E3
(Marlin 펌웨어)		 USB Serial (가상 COM 포트) X / Y / Z 스테퍼 모터 조그 이동(기본 1 mm 단위), 홈 이동, UART 송·수신 메시지 콘솔, 수동 G-code 입력
Digilent Analog Discovery 2 USB (WaveForms SDK) 연결 상태 자동 감지·표시, CH1 입력 전압 파형을 X축=시간 / Y축=전압 그래프로 실시간 표시

2. 설치 방법

2-1. 필요 소프트웨어

  • Python 3.9 이상 — python.org 에서 설치 (Windows 설치 시 "Add Python to PATH" 체크)
  • Python 패키지 — pyserial, matplotlib
  • Digilent WaveForms (AD2 사용 시 필수) — digilent.com 에서 설치. WaveForms 를 설치하면 이 프로그램이 사용하는 SDK(dwf 라이브러리)가 함께 설치됩니다.
  • 보드 USB 드라이버 — SKR mini E3 는 Windows 10 이상에서 표준 CDC 드라이버로 자동 인식됩니다(장치 관리자에 COMx 로 표시).

2-2. 실행 방법 ① — Windows 원클릭 실행 (권장)

  1. Python 3.9 이상을 설치합니다 (설치 시 "Add Python to PATH" 체크).
  2. FEEG_ESD_eSCOPE 폴더의 run_windows.bat 를 더블클릭합니다.
  3. 첫 실행 시 필요한 패키지(pyserial, matplotlib)가 자동 설치된 뒤 프로그램이 뜹니다. 이후에는 더블클릭만 하면 바로 실행됩니다.

2-3. 실행 방법 ② — 단일 EXE 파일 만들기 (Python 없는 PC 배포용)

  1. Python 이 설치된 PC 에서 build_exe.bat 를 더블클릭합니다.
  2. 몇 분 뒤 dist\FEEG_ESD_eSCOPE.exe 가 생성됩니다.
  3. 이 EXE 파일 하나만 다른 PC 에 복사하면, Python 설치 없이 더블클릭으로 실행됩니다. (AD2 사용 시 그 PC 에도 WaveForms 는 설치되어 있어야 합니다.)
처음 만든 EXE 를 실행할 때 Windows Defender SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행" 을 누르면 됩니다.

2-4. 실행 방법 ③ — Linux / macOS

cd FEEG_ESD_eSCOPE
./run_linux_mac.sh

Linux 에서 시리얼 포트 권한 오류(Permission denied)가 나면 sudo usermod -aG dialout $USER 실행 후 재로그인하세요.

2-5. 실행 방법 ④ — 명령줄 수동 실행

cd FEEG_ESD_eSCOPE
pip install -r requirements.txt
python FEEG_ESD_eSCOPE.py
AD2 가 없어도 프로그램은 실행됩니다. 파형 화면은 데모 모드(합성 사인파)로 미리 확인할 수 있습니다.

4. SKR mini E3 (Marlin) 연결하기

  1. 보드를 USB 케이블로 PC 에 연결합니다.
  2. 프로그램 왼쪽 상단 포트 목록에서 보드의 COM 포트를 선택합니다. 목록에 없으면 새로고침을 누르세요.
  3. Baud 는 기본값 115200 을 사용합니다 (Marlin 펌웨어의 BAUDRATE 설정과 같아야 합니다. 일부 펌웨어는 250000).
  4. 연결 버튼을 누르면 상태가 ● 연결됨 으로 바뀌고, 보드가 리셋되면서 부팅 메시지(start, Marlin ... 등)가 UART 콘솔에 표시됩니다.
연결 직후 보드가 자동 리셋되는 것은 정상 동작입니다(USB DTR 신호). 부팅 메시지가 끝난 뒤 모터를 조작하세요.

5. 스테퍼 모터 제어

5-1. 조그 이동

  • 이동 거리 입력란에 원하는 값을 mm 단위로 직접 입력합니다. 기본값은 1 mm 이며, 0.05, 2.5, 25 처럼 소수점 값도 가능합니다. 숫자가 아니거나 0 이하인 값은 경고와 함께 무시됩니다.
  • X+ X− Y+ Y− Z+ Z− 버튼을 누를 때마다 해당 축이 선택한 거리만큼 이동합니다.
  • 버튼 한 번에 실제로 전송되는 G-code: 
    G91                ; 상대 좌표 모드
G0 X1 F1200        ; X축 +1mm 이동 (이송속도 1200 mm/min)
G90                ; 절대 좌표 모드 복귀

5-2. 보조 기능

버튼G-code설명
전체 홈G28X, Y, Z 모든 축 홈 이동
XY 홈 / Z 홈G28 X Y / G28 Z선택 축만 홈 이동
모터 해제M84스테퍼 전원 차단 — 손으로 축을 움직일 수 있음
위치 확인M114현재 좌표를 콘솔에 보고
Marlin 은 기본적으로 홈 이동(G28) 전에는 소프트 엔드스톱 때문에 이동이 제한될 수 있습니다. 이동이 안 되면 먼저 전체 홈을 실행하거나, 콘솔에서 M211 S0(소프트 엔드스톱 해제)을 전송하세요.

6. 테스트 설정 (Test Parameters)

조그 패널 아래의 테스트 설정에서 측정 관련 값을 입력하고 [설정 적용] 버튼으로 확정합니다. 모든 값은 mm 단위 (Search Speed 제외)로 입력합니다.

항목단위규칙
X_scope / Y_scopemm 두 값이 같아야 합니다. 다르면 "X_scope 와 Y_scope 값이 서로 틀립니다" 오류가 표시됩니다.
X_test_distance / Y_test_distancemm 두 값이 같아야 합니다. 다르면 "X_test_distance 와 Y_test_distance 값이 서로 틀립니다" 오류가 표시됩니다.
Search Speed— 0 보다 크고 최대 12 까지만 입력할 수 있습니다. 12 를 넘으면 오류가 표시됩니다.
  • 입력 중에도 값이 서로 다르거나 12 를 넘으면 해당 줄 아래에 빨간 경고 문구가 실시간으로 표시됩니다.
  • [설정 적용] 을 누르면 위 규칙을 모두 검사한 뒤, 통과하면 콘솔에 [설정] X/Y_scope=10 mm, X/Y_test_distance=1 mm, Search Speed=5 적용됨 형태로 기록됩니다. 하나라도 어긋나면 오류 창이 뜨고 적용되지 않습니다.

7. 메시지 콘솔 (UART / Command)

  • 보드와 주고받는 모든 메시지가 실시간으로 표시됩니다. 파란색(>>)은 PC→보드 송신, 녹색(<<)은 보드→PC 수신, 빨간색은 오류, 회색은 프로그램 안내 메시지입니다.
  • 보라색 [동작] 줄은 PC 에서 수행한 모터 제어 행위의 설명입니다. 조그 버튼·홈·모터 해제·위치 확인을 누를 때마다 "무엇을 했는지"가 G-code 와 함께 기록됩니다. 예: 
    [동작] X축 +1 mm 이동 (이송속도 1200 mm/min)
>> G91
>> G0 X1 F1200
>> G90
<< ok
  • 아래 입력창에 임의의 G-code (예: M115, M503)를 입력하고 Enter 또는 전송 버튼으로 보낼 수 있습니다.
  • 지우기 버튼으로 콘솔을 비웁니다. 콘솔은 2000줄을 넘으면 오래된 줄부터 자동 삭제됩니다.

8. Analog Discovery 2 파형 표시

8-1. 연결 상태 표시

  • 프로그램이 2초마다 자동으로 장치를 검색합니다. AD2 를 USB 에 꽂으면 상태등이 ● AD2 연결됨 으로 바뀝니다.
  • WaveForms(SDK)가 설치되어 있지 않으면 "WaveForms SDK 미설치 — 데모 모드만 사용 가능" 으로 표시됩니다.

8-2. 파형 측정

  1. 측정할 신호를 AD2 의 CH1 (1+ / 1−) 단자에 연결합니다.
  2. 샘플레이트(1 kHz ~ 10 MHz), 샘플 수(512~8192), 범위(5 V = 약 ±2.5 V, 50 V = 약 ±25 V)를 선택합니다.
  3. 측정 시작을 누르면 파형이 실시간 갱신됩니다. X축은 시간[ms], Y축은 전압[V] 입니다.
  4. 한 화면에 표시되는 시간 폭 = 샘플 수 ÷ 샘플레이트. 예) 4096 샘플 ÷ 1 MHz = 4.096 ms.
  5. 측정 정지를 누르면 획득이 멈추고 장치가 해제됩니다.

8-3. 데모 모드

"데모 모드(합성 파형)" 를 체크하고 측정을 시작하면, 하드웨어 없이 1 kHz 사인파(진폭 2 V + 잡음)가 표시됩니다. 화면 동작 확인용입니다.

9. 문제 해결 (FAQ)

증상확인 사항
포트 목록에 보드가 안 보임 USB 케이블(데이터 지원 여부) 확인 → 새로고침 클릭 → 장치 관리자에서 COM 포트 인식 확인
연결은 되는데 글자가 깨짐 Baud 불일치입니다. 115200 ↔ 250000 을 바꿔서 재연결하세요.
조그 버튼을 눌러도 안 움직임 ① 홈(G28) 먼저 실행 ② 콘솔의 echo: 오류 메시지 확인 ③ M211 S0 으로 소프트 엔드스톱 해제 후 시도
AD2 상태등이 계속 빨간색 WaveForms 설치 여부 확인 → WaveForms 앱을 닫았는지 확인 (다른 프로그램이 장치를 점유하면 연결 불가) → USB 재연결
측정 시작 시 "장치 열기 실패" WaveForms 등 다른 프로그램이 AD2 를 사용 중입니다. 종료 후 재시도하세요.

10. 안전 주의 사항

  • 모터 이동 전, 이동 경로에 장애물·케이블이 없는지 확인하세요.
  • Z축 하강(Z−) 시 공구/노즐과 베드의 충돌에 주의하세요.
  • AD2 입력 최대 전압(±25 V)을 초과하는 신호를 연결하지 마세요.
  • ESD 관련 실험 시 접지 및 정전기 보호 절차를 준수하세요.
