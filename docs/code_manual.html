1. 전체 아키텍처

1-1. 파일 구성

파일역할
FEEG_ESD_eSCOPE.py 메인 프로그램. Tkinter GUI 전체(App 클래스)와 주기 폴링 루프.

1-2. 스레드 / 데이터 흐름

        [GUI 메인 스레드 (Tkinter)]
        │  after(100ms) ── rx_queue 폴링 ──→ UART 콘솔 표시
        │  after(50ms)  ── data_queue 폴링 ─→ matplotlib 파형 갱신
        │  after(2s)    ── FDwfEnum 폴링 ──→ AD2 연결 상태등 갱신
        │
  ┌─────┴──────────────┐        ┌────────────────────────┐
  │ 수신 스레드          │        │ 획득 스레드              │
  │ MarlinSerial._rx_loop│       │ AD2Scope._acq_loop      │
  │ serial.read() 반복   │        │ 단발 획득 반복           │
  │  → rx_queue.put()   │        │  → data_queue.put()     │
  └─────────────────────┘        └────────────────────────┘
설계 원칙 — Tkinter 위젯은 메인 스레드에서만 조작해야 하므로, 백그라운드 스레드는 절대 GUI 를 직접 건드리지 않고 queue.Queue 에만 데이터를 넣습니다. GUI 는 root.after() 타이머로 큐를 폴링하여 화면을 갱신합니다. 이 구조 덕분에 시리얼 지연이나 AD2 획득 시간이 UI 를 멈추게 하지 않습니다.

2-2. class MarlinSerial

내부 상태

self._ser       # serial.Serial 인스턴스 (미연결 시 None)
self._rx_thread # 수신 스레드 (daemon)
self._running   # 수신 루프 계속 여부 플래그
self.rx_queue   # (종류, 문자열) 튜플 큐 — 종류: "rx"|"tx"|"info"|"error"

connect(port, baud)

self._ser = serial.Serial(port=port, baudrate=baud, timeout=0.1)
self._running = True
self._rx_thread = threading.Thread(target=self._rx_loop, daemon=True)
self._rx_thread.start()
  • timeout=0.1 — read() 가 최대 0.1초만 블록하므로 _running=False 설정 후 스레드가 빠르게 종료됩니다.
  • 연결 시 USB DTR 신호로 보드가 리셋되어 Marlin 부팅 메시지가 수신됩니다(정상).

_rx_loop() — 수신 스레드 본체

buf = b""
while self._running:
    data = self._ser.read(256)        # 최대 0.1초 대기
    if data:
        buf += data
        while b"\n" in buf:           # 개행 단위로 라인 분리
            line, buf = buf.split(b"\n", 1)
            text = line.decode("utf-8", errors="replace").rstrip("\r")
            if text:
                self.rx_queue.put(("rx", text))
  • 바이트 스트림을 버퍼에 누적하다가 \n 이 나올 때마다 한 줄씩 잘라 큐에 넣는 전형적인 라인 프레이밍 방식입니다.
  • errors="replace" — 보레이트 불일치 등으로 깨진 바이트가 와도 예외 없이 � 로 치환해 표시합니다.
  • SerialException 발생(케이블 분리 등) 시 ("error", …) 를 큐에 넣고 루프를 종료 — GUI 가 이를 보고 연결 상태를 "연결 안 됨"으로 되돌립니다.

send_gcode(gcode)

self._ser.write((line + "\n").encode("ascii", errors="replace"))
self.rx_queue.put(("tx", line))       # 송신 에코 → 콘솔에 파란색 표시

Marlin 은 개행(\n)으로 명령 끝을 인식하며, 처리 후 ok 응답을 보냅니다. 송신 내용도 큐에 넣어 콘솔에서 송/수신을 한 흐름으로 볼 수 있게 했습니다.

_log_action(text) — PC 제어 행위 로그

self.rx_queue.put(("action", text))

조그·홈·모터 해제·위치 확인 등 PC 에서 수행한 제어 행위를 사람이 읽을 수 있는 설명("[동작] X축 +1 mm 이동" 등)으로 콘솔에 남긴다. 각 제어 메서드가 G-code 전송 직전에 호출하며, 연결된 상태에서만 기록한다. GUI 는 action 태그(보라색 굵은 글씨)로 표시한다.

jog(axis, distance_mm, feedrate_mm_min=1200) — 핵심 모터 제어

self._log_action(f"[동작] {axis}축 ±{...}mm 이동 (이송속도 ...)")  # 행위 설명
self.send_gcode("G91")                                  # ① 상대 좌표 모드
self.send_gcode(f"G0 {axis}{distance_mm:g} F{feedrate}") # ② 해당 축 이동
self.send_gcode("G90")                                  # ③ 절대 좌표 모드 복귀
단계이유
① G91 "현재 위치에서 ±거리" 로 해석되게 함. 조그 버튼의 의미와 일치.
② G0 X1 F1200 {distance_mm:g} 포맷은 1.0→"1", 0.1→"0.1" 로 깔끔하게 출력. F1200 = 20 mm/s 의 안전한 이송 속도.
③ G90 다른 프로그램/명령이 절대 좌표를 가정하므로 반드시 원상 복구.

기타 명령 래퍼

메서드G-code설명
home(axes="")G28 / G28 X Y 빈 문자열이면 전체 홈, "XY" 처럼 축 문자를 주면 해당 축만.
disable_steppers()M84모터 전원 해제.
get_position()M114현재 좌표 보고 요청.

3. ad2_scope.py — Analog Discovery 2 제어

3-1. SDK 로드 (_load_dwf)

if sys.platform.startswith("win"):
    _dwf = ctypes.cdll.dwf                        # Windows: dwf.dll
elif sys.platform == "darwin":
    _dwf = ctypes.cdll.LoadLibrary("/Library/Frameworks/dwf.framework/dwf")
else:
    _dwf = ctypes.cdll.LoadLibrary("libdwf.so")   # Linux
  • WaveForms SDK 는 C 라이브러리이므로 ctypes 로 직접 바인딩합니다 (별도 pip 패키지 불필요).
  • 로드 실패 시 예외를 삼키고 None 을 반환 — SDK 가 없는 PC 에서도 프로그램 전체는 정상 실행되고, GUI 는 "SDK 미설치" 상태만 표시합니다.
  • sdk_available() / device_count() 는 모듈 레벨 함수로, GUI 의 연결 감지 폴링에 사용됩니다. FDwfEnum(0, &n) 은 장치를 열지 않고 개수만 세므로 주기 호출에 안전합니다.

3-2. class AD2Scope

open(demo=False)

dwf.FDwfDeviceOpen(ctypes.c_int(-1), ctypes.byref(self._hdwf))
if self._hdwf.value == 0:            # hdwfNone = 열기 실패
    dwf.FDwfGetLastErrorMsg(err)
    raise RuntimeError(...)
  • 인덱스 -1 = "첫 번째 사용 가능한 장치 자동 선택".
  • 다른 프로그램(WaveForms 앱 등)이 장치를 점유 중이면 핸들이 0 으로 반환되며, SDK 의 마지막 오류 메시지를 읽어 예외로 올립니다.
  • demo=True 면 하드웨어를 전혀 건드리지 않고 플래그만 세웁니다.

start(sample_rate, n_samples, ch_range) → _acq_loop()

획득 스레드가 시작될 때 한 번 수행하는 스코프 설정:

FDwfAnalogInFrequencySet(hdwf, sample_rate)   # 샘플링 주파수 [Hz]
FDwfAnalogInBufferSizeSet(hdwf, n_samples)    # 획득 버퍼 크기 (최대 8192)
FDwfAnalogInChannelEnableSet(hdwf, 0, 1)      # CH1(index 0) 활성화
FDwfAnalogInChannelRangeSet(hdwf, 0, ch_range)# 전압 범위 (5V 또는 50V)
time.sleep(0.1)                               # 아날로그 프론트엔드 안정화

이후 무한 반복하는 단발(Single) 획득 루프:

while self._running:
    FDwfAnalogInConfigure(hdwf, 0, 1)         # 획득 1회 시작
    while ...:                                # 완료 폴링
        FDwfAnalogInStatus(hdwf, 1, &sts)
        if sts == DwfStateDone: break         # DwfStateDone = 2
    FDwfAnalogInStatusData(hdwf, 0, buf, n)   # 전압 배열 읽기 [V]
    self._push(1.0/sample_rate, list(buf))    # (샘플주기, 데이터) 전달
    time.sleep(0.03)                          # 화면 갱신 ~20-30fps 제한
연속(Record) 모드 대신 단발 획득을 반복하는 이유 — 오실로스코프처럼 "한 화면 분량(샘플 수 ÷ 샘플레이트)의 파형"을 통째로 받아 그리는 것이 목적이므로 구현이 단순하고 프레임 간 데이터 유실 걱정이 없습니다.

_push(dt, data) — 프레임 드롭 정책

try:
    self.data_queue.put_nowait((dt, data))
except queue.Full:          # GUI 가 못 따라오면
    self.data_queue.get_nowait()   # 가장 오래된 프레임을 버리고
    self.data_queue.put_nowait((dt, data))  # 최신 프레임을 넣는다

큐 크기를 4로 제한하고 가득 차면 오래된 것을 버립니다. 화면에는 항상 최신 파형이 표시되고 메모리가 누적되지 않습니다.

_demo_loop() — 데모 모드

1 kHz 사인파(진폭 2 V) + 가우시안 잡음(σ=0.05 V)을 math.sin 으로 합성해 실제 획득과 같은 형식으로 큐에 넣습니다. phase 를 누적시켜 프레임마다 파형이 이어지도록 했습니다.

4. FEEG_ESD_eSCOPE.py — 메인 GUI

4-1. class App(tk.Tk) 초기화

self.marlin = marlin_serial.MarlinSerial()
self.scope  = ad2_scope.AD2Scope()
self._build_ui()
self.after(100, self._poll_marlin_rx)     # UART 콘솔 갱신 루프
self.after(50,  self._poll_scope_data)    # 파형 갱신 루프
self.after(500, self._poll_ad2_presence)  # AD2 감지 루프
self.protocol("WM_DELETE_WINDOW", self._on_close)

레이아웃은 grid 2열 구조 — 왼쪽(고정폭): Marlin 연결·조그·콘솔, 오른쪽(신축): AD2 설정 + matplotlib 캔버스.

4-2. Marlin 연결 UI (_build_marlin_conn / _toggle_marlin)

  • 포트 콤보박스는 list_serial_ports() 결과로 채우며, 새로고침 버튼이 _refresh_ports() 를 다시 호출합니다.
  • _toggle_marlin() 은 연결/해제를 한 버튼으로 토글하고, 상태 라벨을 ● 연결됨 / ● 연결 안 됨 으로 갱신합니다.

4-3. 조그 패드 (_build_jog / _jog)

self.step_var = tk.StringVar(value="1")   # 기본 1mm, Entry 로 자유 입력
...
def _jog(self, axis, sign):
    try:
        step = float(self.step_var.get().strip())   # mm 단위 사용자 입력 파싱
    except ValueError:
        messagebox.showwarning(...); return          # 숫자가 아니면 경고
    if step <= 0:
        messagebox.showwarning(...); return          # 0 이하도 거부
    self.marlin.jog(axis, sign * step)
  • 이동 거리는 Entry 입력란에 mm 단위로 자유 입력하며 기본값은 1 mm. 소수점 값도 허용되고, 잘못된 입력은 경고 대화상자로 걸러진다.
  • 버튼 배치는 십자형(X/Y) + 우측 세로(Z) 로, 각 버튼은 lambda: self._jog(axis, ±1) 콜백을 가집니다.
  • 홈/모터해제/위치확인 버튼은 MarlinSerial 의 래퍼 메서드를 직접 호출.

4-3b. 테스트 설정 패널 (_build_test_params / _apply_test_params)

# 입력 변수 (StringVar): xscope_var, yscope_var, xtest_var, ytest_var, speed_var
for var in (...):
    var.trace_add("write", lambda *_: self._update_param_warnings())  # 실시간 경고
  • X_scope / Y_scope, X_test_distance / Y_test_distance 는 mm 단위 입력이며, 각 쌍은 같은 값이어야 한다. _pair_differs() 가 두 입력이 모두 숫자일 때만 비교하여, 다르면 해당 줄 아래 빨간 경고 라벨을 실시간 표시한다.
  • Search Speed 는 0 초과 최대 12 까지만 허용. 초과 입력 시 실시간 경고가 뜬다.
  • _apply_test_params() — [설정 적용] 버튼 콜백. 숫자 파싱 → 쌍 일치 검사 → 속도 범위 검사 순으로 검증하고, 하나라도 실패하면 messagebox.showerror 로 어떤 값이 틀렸는지 알린 뒤 중단한다. 모두 통과하면 self.test_params dict 에 저장하고 콘솔에 [설정] … 줄(action 태그)을 남긴다.

4-4. 메시지 콘솔 (UART / Command) (_build_console / _poll_marlin_rx / _append_console)

  • ScrolledText 를 state="disabled" 로 두어 사용자가 직접 수정하지 못하게 하고, 추가할 때만 잠시 normal 로 바꿉니다.
  • 메시지 종류별 태그 색상: rx=녹색, tx=파랑, error=빨강, info=회색. 접두어 >>(송신) / <<(수신)를 붙입니다.
  • _poll_marlin_rx() 는 100 ms 마다 rx_queue 를 모두 비우고, error 수신 + 연결 끊김이면 연결 버튼/상태를 자동 복구합니다.
  • 2000줄 초과 시 앞 200줄을 삭제해 장시간 사용 시 메모리를 보호합니다.

4-5. AD2 패널 (_build_ad2_panel 등)

연결 상태등 — _poll_ad2_presence()

if self.scope.is_open:            # 측정 중이면 항상 녹색 유지
    self._set_lamp(True, "AD2 연결됨 (사용 중)")
elif not ad2_scope.sdk_available():
    self._set_lamp(False, "WaveForms SDK 미설치 — 데모 모드만 사용 가능")

상태등은 tk.Canvas 의 원(oval) 색상을 녹색/빨강으로 바꾸는 방식입니다. 측정 중에는 FDwfEnum 을 부르지 않도록 is_open 분기를 먼저 둡니다.

측정 시작/정지 — _toggle_scope()

  2. scope.open(demo) → scope.start(rate, n, range) 로 획득 스레드를 시작하고 버튼 텍스트를 "측정 정지"로 바꿉니다.
  3. 정지 시 stop()(스레드 join) → close()(장치 해제) 순서.

4-6. 종료 처리 — _on_close()
